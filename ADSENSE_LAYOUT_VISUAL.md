## Ad Slot Details

### AD #1: Top Banner
- **Position:** Below header, above main content
- **Format:** Leaderboard (728×90) / Mobile (320×50)
- **Visibility:** All devices
- **Sticky:** No
- **Component:** `AdBanner position="top-banner"`
- **Best for:** Brand awareness, product launches
- **Expected CTR:** 0.3-0.5%

### AD #2: Left Sidebar
- **Position:** Left side of content area
- **Format:** Half-page ad (300×600)
- **Visibility:** Desktop only (1024px+)
- **Sticky:** Yes - sticks while scrolling
- **Component:** `AdBanner position="left-sidebar"`
- **Best for:** Brand building, high-value ads
- **Expected CTR:** 0.4-0.7%

### AD #3: Right Sidebar
- **Position:** Right side of content area
- **Format:** Half-page ad (300×600)
- **Visibility:** Desktop only (1024px+)
- **Sticky:** Yes - sticks while scrolling
- **Component:** `AdBanner position="right-sidebar"`
- **Best for:** High-paying advertisers, brand ads
- **Expected CTR:** 0.4-0.7%

### AD #4: Results Separator Mobile
- **Position:** Between upload and results (when shown)
- **Format:** Mobile banner (320×50)
- **Visibility:** Mobile and tablet only (<1024px)
- **Sticky:** No
- **Component:** `AdBanner position="results-separator-mobile"`
- **Best for:** Attention capture at natural break point
- **Expected CTR:** 0.2-0.4%

### AD #5: Post-Results Desktop
- **Position:** Below results section
- **Format:** Leaderboard (728×90)
- **Visibility:** Desktop only, when results shown
- **Sticky:** No
- **Component:** `AdBanner position="post-results-desktop"`
- **Best for:** Capture attention after user satisfaction
- **Expected CTR:** 0.3-0.5%

### AD #6: Pre-Features Mobile
- **Position:** Before features section
- **Format:** Medium rectangle (300×250)
- **Visibility:** Mobile and tablet only (<1024px)
- **Sticky:** No
- **Component:** `AdBanner position="pre-features-mobile"`
- **Best for:** Additional monetization on mobile
- **Expected CTR:** 0.2-0.4%

### AD #7: Pre-FAQ Banner
- **Position:** Immediately before FAQ section
- **Format:** Leaderboard (728×90) / Mobile (320×50)
- **Visibility:** All devices
- **Sticky:** No
- **Component:** `AdBanner position="pre-faq"`
- **Best for:** Users seeking information
- **Expected CTR:** 0.3-0.5%

### AD #8: Post-FAQ Banner
- **Position:** Immediately after FAQ section
- **Format:** Leaderboard (728×90) / Mobile (320×50)
- **Visibility:** All devices
- **Sticky:** No
- **Component:** `AdBanner position="post-faq"`
- **Best for:** Satisfied users (high engagement)
- **Expected CTR:** 0.3-0.5%

### AD #9: Footer Banner
- **Position:** Bottom of page, before footer
- **Format:** Leaderboard (728×90) / Mobile (320×50)
- **Visibility:** All devices
- **Sticky:** No
- **Component:** `AdBanner position="footer-banner"`
- **Best for:** Last impression before exit
- **Expected CTR:** 0.1-0.3%

## Key Features

### ✅ Responsive Design
- Ads automatically resize based on device
- Sidebar ads hidden on mobile
- Proper spacing maintained across all breakpoints

### ✅ Sticky Sidebars
- Left and right ads stick while scrolling on desktop
- Top position: 96px (adjusts for header height)
- GPU accelerated for smooth scrolling

### ✅ Core Web Vitals Optimized
- Fixed ad dimensions prevent layout shifts (CLS = 0)
- AdSense script async (non-blocking)
- CSS containment prevents layout recalculations
- No ads above the fold (except top banner)

### ✅ User Experience
- Natural ad placement (no intrusion)
- Proper spacing (16-32px between ads and content)
- Blends with design (matching colors/borders)
- No blocking of critical functionality
- Mobile-friendly (no sidebar clutter)

### ✅ Monetization
- 9 strategic ad placements
- Multiple format types (sidebars, banners, rectangles)
- High-visibility positions
- Sticky ads increase engagement

## Spacing & Margins

All ad containers include proper spacing:

```
Desktop Sidebar Ads:
├─ 24px gap from edge
├─ 16px padding within sidebar
├─ 96px from top (adjusts for header)
└─ Sticky while scrolling

Horizontal Banners:
├─ 24px top margin
├─ 24px bottom margin
├─ Full width (responsive)
└─ Auto margins for centering

Mobile Ads:
├─ 12px margins on mobile
├─ 16px margins on tablet
├─ Full width minus padding
└─ No sidebars to preserve space
```

## Loading Performance

Ad loading timeline:

```
1. Initial Page Load
   └─ AdSense script loads async (non-blocking)

2. Page Render
   ├─ Main content renders immediately
   ├─ Ad placeholders show while loading
   └─ Ads appear gradually

3. After Ads Loaded
   ├─ Google AdSense serves targeted ads
   ├─ Ads update every 30-60 seconds
   └─ Real-time bidding optimizes earnings
```

**Page Load Impact:**
- Script: < 100ms (async)
- Ads serving: 500ms - 2s (parallel)
- **Total impact on LCP: Minimal (ads below fold)**
